## What this run taught the skill

- **Nested agent docs.** next.js has `AGENTS.md` in `apps/bundle-analyzer/`, `packages/next/`, `turbopack/` and two more. The bundle analyzer's says the React Compiler handles memoisation — exactly what sweep 7 checks — and the rules pack only read the root one. `rules-pack.sh` now lists every nested `AGENTS.md` / `CLAUDE.md` and the reviewer reads the ones that rule a file in scope (1.0.3).
- **The hunk exception is a line count, not a judgement.** One reviewer read a 1 058-line file by hunks; the threshold is 1 500 and the reviewer prompt now says so explicitly.
- **Project config matters on big monorepos.** Excluding tests, examples and vendored code is a three-line `.audit-code/config.env`; without it the delta is mostly noise.
